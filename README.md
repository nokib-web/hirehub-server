# HireHub Server

A complete Node.js backend for the Job Recruitment System.

## Tech Stack
-   **Node.js**
-   **Express.js**
-   **TypeScript**
-   **MongoDB + Mongoose**
-   **JWT for Auth**
-   **Security**: Helmet, Morgan, Express Mongo Sanitize, Rate Limiter

## Getting Started
1.  Clone the repository: `git clone https://github.com/nokib-web/hirehub-server.git`
2.  Install dependencies: `npm install`
3.  Set up environment variables in `.env` (refer to `.env.example`).
4.  Run in development mode: `npm run dev`
5.  Build for production: `npm run build`
6.  Start production server: `npm run start`
